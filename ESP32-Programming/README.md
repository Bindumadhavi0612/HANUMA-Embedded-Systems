ESP32 Programming

Overview
The ESP32 was used as one of the main embedded controllers in the HANUMA mine monitoring rover.
I worked on the ESP32 programming and its integration with the project hardware.

My Work
- Developed and tested the ESP32 programming required for the rover.
- Worked on integrating the ESP32 with the connected sensors and hardware components.
- Tested the ESP32 functionality as part of the overall rover system.

Hardware
- ESP32 development board
- Sensors
- Motor/rover hardware
- Supporting electronic components

Project Context
This work was completed as part of the HANUMA team project. The repository focuses specifically on my contribution to the ESP32 programming and embedded hardware integration.
