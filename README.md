HANUMA – Hazard Analysis & Navigation Unit for Mine Assistance

Project Overview :
HANUMA (Hazard Analysis & Navigation Unit for Mine Assistance) is a team-based embedded mine monitoring rover designed to assist in monitoring hazardous mine environments.
The system integrates an ESP32, Raspberry Pi, sensors, GPS and cloud monitoring to collect and monitor information from the rover.

Technologies & Components :
- ESP32
- Raspberry Pi
- Sensors
- GPS
- ThingSpeak
- Arduino IDE
- Embedded Systems
- Hardware Interfacing
